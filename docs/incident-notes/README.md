# Incident Notes

These notes are writeups of real infrastructure and platform failure modes.

Each incident should explain:

- Symptom.
- Impact.
- Root cause.
- Diagnosis.
- Fix.
- Verification.
- Prevention or future improvement.

The goal is to make the next similar failure boring.
